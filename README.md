
# Student Registration Form and Table

## 🎯 Objective

To create a Student Registration Form and a table using HTML. The task demonstrates basic HTML form elements, input types, labels, buttons, and table structure.

## 📌 Task Description

Create a webpage containing a Student Registration Form where users can enter their personal details, select their gender, choose their skills, and enter their date of birth.

Below the form, display a table containing dummy student data with details such as name, email, gender, skills, and date of birth.

## 🛠️ Technologies Used

- HTML5

## ✨ Features

### Student Registration Form

- Full Name input field
- Email input field
- Password input field
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth selection using a date input
- Register button to submit the form
- Required fields for basic form validation

### Submitted Students Table

- Displays dummy student records
- Includes columns for Name, Email, Gender, Skills, and DOB
- Uses table headings and table data cells
- Uses a border and cell padding for table formatting

## 📚 Concepts Practiced

- Basic HTML document structure
- HTML5 doctype and language attribute
- Meta charset and viewport attributes
- Headings using `<h2>`
- Forms using `<form>`
- Labels using `<label>`
- Input types: `text`, `email`, `password`, `radio`, `checkbox`, and `date`
- The `required` attribute
- The `placeholder` attribute
- Submit buttons using `<button>`
- Line breaks using `<br>`
- Horizontal lines using `<hr>`
- Inline CSS using the `style` attribute
- Tables using `<table>`, `<tr>`, `<th>`, and `<td>`
- Table attributes such as `border` and `cellpadding`
